# Semi-Automatic Mask Annotation Package

## Overview

This package provides the code and example data used in our semi-automatic pixel-level mask annotation pipeline.

The pipeline consists of two stages:

1. **Candidate-mask generation:** the original and edited images are aligned, and multiple candidate masks are generated using different thresholds.
2. **Human review:** an annotator inspects the candidate masks and selects the one that best represents the actual edited region.

For reviewer convenience, the aligned images and candidate masks for the provided samples have already been generated and included in the package. Therefore, reviewers can directly open `code/candidate_mask_review.html` and begin the review process. Running `generate_candidate_masks.py` is optional and is only needed to reproduce or test the candidate-mask generation stage.

The package has the following structure:

```text
MLLM-Edit_Mask_Annotation_Pipeline/
├── README.md
├── code/
│   ├── generate_candidate_masks.py
│   └── candidate_mask_review.html
└── dataset/
    ├── README.md
    ├── QwenImageEditPlus2511_natural/
    └── QwenImageEditPlus2511_text/
```

## Package Contents

### `code/`

The `code/` directory contains the two components of the annotation pipeline:

- `generate_candidate_masks.py`: aligns the original and edited images and generates multiple candidate masks under different thresholds.
- `candidate_mask_review.html`: provides a local browser interface for reviewing the generated candidates and recording the selected mask.

### `dataset/`

The `dataset/` directory contains the Natural and Text subsets used to demonstrate the annotation process.

Each subset has the following structure:

```text
QwenImageEditPlus2511_natural/
├── 0_real/
├── 1_fakesample/
├── align/
├── mask/
└── prompt.csv
```

The Text subset follows the same structure.

- `0_real/`: original images.
- `1_fakesample/`: edited images.
- `align/`: aligned original images generated by `generate_candidate_masks.py`.
- `mask/`: candidate masks organized by threshold.
- `prompt.csv`: editing instructions and sample information used by the review interface.

Images in `0_real/` and `1_fakesample/` are paired by filename stem.

The candidate masks are stored in threshold-specific subdirectories, for example:

```text
mask/
├── 0/
├── 2/
├── 4/
├── 6/
├── 8/
├── 10/
├── 15/
├── 20/
├── 25/
├── 30/
└── ...
```

Each threshold folder contains one candidate mask for each sample.

## Quick Start for Reviewers

The aligned images and candidate masks are already included in the package. Reviewers do not need to install Python packages or run the mask-generation script before using the review interface.

1. Open:

```text
code/candidate_mask_review.html
```

2. Use a Chromium-based browser, such as Google Chrome or Microsoft Edge.

3. Click **Select directory**.

4. Select one complete subset directory:

```text
dataset/QwenImageEditPlus2511_natural/
```

or:

```text
dataset/QwenImageEditPlus2511_text/
```

5. Allow the browser to read the selected local directory.

6. Inspect the original image, aligned original image, edited image, editing instruction, and candidate masks.

7. Double-click the candidate mask that best represents the actual edited region.

8. If none of the candidates is suitable, click **No suitable threshold**.

9. Use **Previous**, **Jump**, and **Next** to navigate between samples.

10. Click **Export CSV** to save the annotation results.

The exported CSV records the selected threshold for each sample. Samples marked with **No suitable threshold** are recorded as `None`.

## Step 1: Generate Candidate Masks

This step is optional for reviewers because the aligned images and candidate masks for the provided samples are already included in the package.

It is only necessary when reproducing or testing the candidate-mask generation process.

### Install Dependencies

```bash
pip install numpy pillow tqdm opencv-python
```

### Select the Dataset Subset

Open:

```text
code/generate_candidate_masks.py
```

Set the subset to process.

For the Natural subset:

```python
DATA_TYPE = "natural"
```

For the Text subset:

```python
DATA_TYPE = "text"
```

### Run the Script

Run the script from the package root:

```bash
python code/generate_candidate_masks.py
```

For each matched original-edited image pair, the script:

1. reads the original and edited images;
2. aligns the original image with the edited image;
3. computes their pixel-level difference;
4. generates candidate masks using multiple thresholds;
5. saves the aligned image and candidate masks in the corresponding subset directory.

The outputs are saved to:

```text
align/
mask/<threshold>/
```

For example:

```text
dataset/QwenImageEditPlus2511_natural/
├── align/
└── mask/
    ├── 0/
    ├── 2/
    ├── 4/
    ├── 6/
    ├── 8/
    └── ...
```

## Step 2: Review and Select Masks

Open:

```text
code/candidate_mask_review.html
```

A Chromium-based browser, such as Google Chrome or Microsoft Edge, is recommended.

After selecting a complete dataset subset directory, the interface displays the following information for each sample:

- the original image;
- the aligned original image;
- the edited image;
- the editing instruction;
- all candidate masks generated under different thresholds.

The annotator should compare the candidate masks with the original and edited images and select the mask that best represents the actual edited region.

A candidate mask is selected by double-clicking it.

If none of the candidate masks is suitable, the annotator should click:

```text
No suitable threshold
```

The interface provides the following controls:

- **Previous**: move to the previous sample.
- **Next**: move to the next sample.
- **Jump**: move directly to a specified sample.
- **No suitable threshold**: mark the current sample as having no acceptable candidate mask.
- **Export CSV**: export the current annotation results.

## Annotation Workflow

The complete annotation workflow is:

```text
Original image + Edited image
                │
                ▼
         Image alignment
                │
                ▼
    Pixel-difference calculation
                │
                ▼
Candidate masks under multiple thresholds
                │
                ▼
     Human review and selection
                │
                ▼
       Exported annotation CSV
```

The Python script performs image alignment and candidate-mask generation, while the HTML interface is used for human review and final mask selection.
